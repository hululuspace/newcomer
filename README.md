## 四、日常更新资讯（只改一个地方）

打开 `index.html`，找到 `★★★ 内容维护区 ★★★` 那段，里面是 `NEWS` 数组：

```js
const NEWS = [
  { date:"2026-11-18", tag:"省提名", title:"标题", excerpt:"两句话摘要", link:"" },
];
```

- 新增：复制上面一行，粘在最前面（越新越靠上），改日期/标签/标题/摘要。
- `link` 填原文网址就是可点击的；留空就只是文字。
- 首页会自动取最新 3 条；资讯页会自动生成筛选按钮，**不用手动改任何 HTML**。
- 想加新分类（比如"生活成本"），在 `TAGS` 数组里加一个词就行。

6 条示例资讯是我按"解读 + 经验"口吻写的，**没有写具体名额和分数线**，因为政策数字经常变、写死了会出错。建议你也保持这个写法：讲判断，不讲数字。

## 五、放到 GitHub（约 10 分钟）

1. 新建一个仓库，比如 `shuangshou-site`，设为 Public。
2. 把 `index.html` 上传到仓库根目录（`assets/` 一起传，以后换成自己图片要用）。
3. 仓库 → **Settings → Pages** → Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)` → Save。
4. 等 1–2 分钟，地址是 `https://你的用户名.github.io/shuangshou-site/`。
5. 想用自己域名：Settings → Pages → Custom domain 填域名，再到域名商加一条 CNAME。

**图片**：现在这 4 张图用的是临时托管链接（能显示、但长期不稳）。要换成自有图片：把图片放进 `assets/`，再把代码里 `src="https://media.doubao.com/..."` 那一整段改成 `src="assets/hero-prairie.jpg"`（四个文件名分别对应：`hero-prairie.jpg`／`greenhouse.jpg`／`family.jpg`／`highway.jpg`）。
